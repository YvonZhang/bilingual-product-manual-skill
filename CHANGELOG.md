# Changes

## 2.0.0

Hardware brochures and specifications now have independent A4 blue/white templates, bilingual input schema, evidence references, image/model/interface review, consistent visible logo width, and complete build/render/check commands. Brochures preserve the two-page layout and equal parameter-column bottoms; native DOCX specifications support grouped parameters and continuing tables. Missing optional material is omitted with an internal gap record.

Includes fictional hardware samples, long-title/54-row/no-image boundary coverage, an independent forward test, document revision regression, source-style measurements, path relocation, and software regression evidence. Original software templates remain available as a separate category. Prior software-only validation is retained as v1 history.

## 1.0.0

Initial bilingual software-operation manual template with editable DOCX, PDF rendering, stable table-of-contents caches and fictional examples.
