# 固定样式契约

## 范围

基准来自一组中英文软件操作手册：中文 40 页、英文 34 页，单节、纵向、步骤和界面截图为主。硬件彩页 2 页和规格书 4 页具有不同信息结构，未合并进本模板。以下记录只含排版规则，不保留任何原产品事实。

| --- | --- |

| 正文 | 11 pt，段后 7 pt；英 271/240 倍行距，中 288/240 倍行距 |
| 封面与目录标题 | Title，29 pt 粗体，段后 22 pt，259/240 倍行距 |
| 版本副标题 | Subtitle，17 pt，段后 20 pt |
| 一级标题 | 19 pt 粗体，段后 14 pt |
| 二级标题 | 15 pt 粗体，段前 18 pt、段后 10 pt |
| 三级标题 | 12 pt 粗体，段前 14 pt、段后 8 pt |
| 四级标题 | 11 pt 粗体，段前 10 pt、段后 5 pt |
| 图注 | 9 pt，505964，段后 11 pt，居中 |

保留中文样式中的较宽行距；字体替代不属于无损还原。模板来自审计的样式定义和页面几何，已去除历史产品正文、媒体、关系及元数据。基础模板采用可编辑 OOXML 段落样式，不是整页图片。

## 组件与内容槽

| 组件 | 输入 / 行为 |
| --- | --- |
| 封面 | 顶部留白与 10 pt 文档类型；产品标题、版本、适用范围；可选品牌和联系方式 |
| Logo | 仅输入时使用，封面页眉中宽 1.1 in；不带入任何默认品牌图 |
| 长标题 | 自然换行，不缩小字号；超出可用封面容量时要求简短 `meta.title` |
| 目录 | 一、二级标题，右对齐点引导线，二级缩进 0.2 in；长标题允许换行 |
| 页眉 | 产品短名；封面不显示运行页眉 |
| 页脚 | 手册类型、版本；右侧当前页 / 总页；封面不显示，目录从物理第 2 页计数 |
| 标题 | 共用章节 ID，自动层级编号；禁止跨级跳跃，允许 1..4 级 |
| 分页 | 封面、目录后明确换页；章节通过 page_break 指定；标题与下段同页 |
| 操作步骤 | 11 pt，当前小节内连续编号；控件文字用粗体 |
| 图片 | 用户 PNG/JPEG，保留纵横比、居中，最大 6.9 × 5.4 in，与图注同页 |
| 图注 | 按全文连续编号；用 figure.id 维持中英一一对应 |
| 表格 | 扩展组件：10 pt，浅灰表头、D9D9D9 边框、约 4.5 pt 内边距，重复表头，自适应行高；每条记录整行留页，过高记录要求拆分 |
| 缺资料 | 必填项缺失时拒绝生成；可选项省略；缺口只进内部报告 |

## 有意的泛化差异

原稿品牌、联系方式、Logo、真实截图和业务正文全部剥离。原稿中的固定截图数量与具体章节名称不作为模板内容。图号改为连续编号，以避免插入/省略章节后失配。目录各层页码统一到正文右边缘，修正原稿二级页码略向左错开的情况。封面品牌留白可随长标题缩短，保留字号。表格为本次复用要求补充，原软件手册没有原生表格。源文件历史遗留的无效关系、旧页脚图形和私人元数据不保留。

以上是固定视觉系统的复用，不保证替换不同长度内容后每页像素或总页数相同。检查目标是页形、角色样式、节奏、页眉页脚和组件行为一致，以及内容无损。

## 验收

检查 DOCX 页面几何、上述样式、图片纵横比、目录与真实页码、PNG 可见文字和连续页码。逐页目检中英最终样张。不同机器的字体与渲染器需单独记录；不把同机目录搬迁测试说成已完成多操作系统认证。
