# 独立虚构产品资料

下列内容完全虚构，仅用于验证技能，不代表任何真实产品能力。

产品：雪松队列工作台 / Cedar Queue Workbench。版本 0.7.2。
用途：在演示队列中整理待办卡片，适用于培训演示组织者。
操作者使用组织者分配的演示账户，资料没有提供固定密码。

流程一：打开 Queue；选择 New card；填写 Title 与 Owner；点击 Save。卡片显示在队列顶部。
流程二：在 Search 输入标题关键词，点击 Search；点击 Reset 清空筛选条件。
流程三：选择 Export text；下载当前筛选结果的文本文件。单次导出最多 25 张卡片。
队列状态每 20 s 刷新。演示工作区最多保留 150 张卡片。
