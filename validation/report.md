# v2.0.0 验收记录

日期：2026-10-20。当前范围以 **`hardware-brochure` 和 `hardware-specification`** 为重点，保留独立的 `software-manual`。本版本完成本地生成、渲染、原样式对照、独立前向测试及软件回归。所有分享样张、参数、品牌和图像均明确虚构。

原件包含 6 份硬件彩页/规格书和 4 份软件操作手册。硬件与软件版式分别建模；原件仅只读分析，10 份文件前后哈希一致，原内容和对照图均未进入分享包。v1 的软件验收保留在 [历史记录](report-v1-software.md)，不会用它替代本次硬件验收。

## 已发现并修复

1. 原生表格最小行高重复包含单元格留白。改为内容行高下限，实际普通参数行恢复为参考的 21.65 pt；不设置会裁切正文的固定行高。
2. Word 默认样式使 Logo 和文档类型的对齐偏离参考。Logo 改为与原版式一致的页面锚定；去除 Header 默认居中制表位；实际 PDF 检查左右边缘和 Logo 宽度。
3. 原生空白文档容器带有默认 bibliography customXml 和缩略图。样式模板清除这些非版式数据；输出仅保留所需文档结构。
4. 独立前向测试发现必填 `meta.version` 未出现在成品，且原检查漏报。四份硬件文档统一显示资料版本，QA 独立检查实际 PDF；同一独立输入的最终 10 页均有正确版本。
5. 三行长标题的浮点高度边界误拒绝。增加排版容差，已用三行英文正式名称完成真实渲染验证；超出容量的文案仍明确失败。
6. 无图边界输入删除了对“图示接口”的文案引用，保持资料和成品语义一致。生成器不会自行编造新描述；使用者需连同图片引用核对文案。

## 仍未覆盖的边界

- 未在第二台物理机器或 Windows/Linux 完成渲染。已证明本机路径搬迁，不把它声称为跨系统实测；目标环境必须安装兼容依赖与合法字体并重新验收。
- 自动数字/单位检查不能证明翻译语义或来源真实性；图片审核标记也不能替代人工检查实际接口。新产品仍需按资料核验。
- 彩页固定两页，过量内容会拒绝；规格书可扩页。参考还原指固定设计规则，换内容、字体、Logo 后不承诺逐像素等同于原产品。
- 主样张性能页只有两行虚构指标，留白属于输入长度，不添加假指标填页；无性能证据时整个性能页省略。

当前没有未修复的本地测试失败。上传状态由任务的 GitHub 回执记录；此技能本身不自动上传，也不改变仓库权限。
